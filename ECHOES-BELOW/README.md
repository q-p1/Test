# ECHOES BELOW

Production target: Unity 6, PC-first cinematic third-person survival horror with responsive controller and touch support.

## Current production priority
Chapter 1 only. Chapters 2–10 remain locked until Chapter 1 passes the completion gate.

## Production rule
Progress is counted only from verified playable artifacts. Plans, prompts, generated concepts, or agent status messages do not count as implementation.

## Chapter 1 completion gate
Chapter 1 is complete only when the real game build launches, can be played from intended start to intended end, all required Chapter 1 systems function in context, and end-to-end QA finds no known progression blockers or softlocks.

## Core direction
- Third-person over-the-shoulder
- Hand-authored environments
- Story/exploration first, with measured stealth/combat
- Psychological tension rather than jump-scare spam
- Nearly invisible HUD
- English voice direction with English/Arabic subtitles and UI
- PC-first, controller-ready, responsive secondary iPad/iPhone support

Story spoilers and unrevealed narrative details should stay out of public-facing documentation.
